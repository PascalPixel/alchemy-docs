---
title: The Broken Seal
description: How Golden Sun works underneath, explained from its decompiled code.
---

This is the first Golden Sun, rebuilt from readable C that compiles back into
the exact original cartridge, in all six languages. These pages explain how the
game works underneath: what happens during a battle round, how the game works
out damage, how a town's people and events are set up, and how Psynergy pushes
things around on the field.

Battles are a good place to start. [How a battle runs](/tbs/battle/battles#how-a-battle-runs)
follows one from the first menu to the spoils, and
[how an ability resolves](/tbs/battle/battles#how-an-ability-resolves) goes
through the sums behind every hit and heal. Each ability has its own page
under [Abilities](/tbs/abilities), with a recording of the cast and the code
that draws it.

The towns and dungeons are under [Places](/tbs/places), in the order the story
reaches them. Each place shows what its code sets up: who stands where, what
happens when you talk to them or search a spot, and how the story changes it.

The rest is grouped by the part of the game it explains:
[World](/tbs/world) for walking around, [Battle](/tbs/battle),
[Menus](/tbs/menus), [Game rules](/tbs/game) for stats, items, Djinn and
levels, and [Engine](/tbs/engine) for what everything else runs on. If you
want the code itself, every file is under [Source](/tbs/source), near the
bottom of the sidebar.

Some code differs between the Japanese release and the translations; where it
does, the pages show each version.
