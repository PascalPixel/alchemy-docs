The questions people bring, and where each is answered:

- **Where is the code for a move?** [Abilities](/docs/tbs/abilities) names the
  function that plays it; [How to find an effect](/docs/tbs/battle/effects#how-to-find-an-effect)
  shows how to read and change it.
- **How does a battle run, from the first menu to the spoils?**
  [How a battle runs](/docs/tbs/battle/battles#how-a-battle-runs).
- **How much damage does a move do, and what decides it?**
  [How an ability resolves](/docs/tbs/battle/battles#how-an-ability-resolves).
- **Where does something happen in a town or dungeon?** [Places](/docs/tbs/places)
  names the scene; [How to find a scene and an event in it](/docs/tbs/world/scenes#how-to-find-a-scene-and-an-event-in-it)
  finds the event, and [How a scene runs](/docs/tbs/world/scenes#how-a-scene-runs) explains it.
- **How does a field Psynergy such as Move or Reveal work?**
  [How to find a field Psynergy](/docs/tbs/world/objects#how-to-find-a-field-psynergy).
- **How do I change a menu screen or a shop?**
  [How to change a screen](/docs/tbs/menus/menus#how-to-change-a-screen) and
  [How to change a counter](/docs/tbs/menus/shops#how-to-change-a-counter).

Each folder of the code has a guide, grouped by what it covers:
[World](/docs/tbs/world), [Battle](/docs/tbs/battle), [Menus](/docs/tbs/menus),
[Game rules](/docs/tbs/game) and [Engine](/docs/tbs/engine). Every file is
under [Source](/docs/tbs/source). [Matching](/docs/tbs/matching) explains how
the build is judged and what the markers in the code mean.

Code inside `#if` differs by edition; the pages show every branch as the
source has it.
