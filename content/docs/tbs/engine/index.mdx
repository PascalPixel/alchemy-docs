---
title: Engine
description: The runtime, graphics, sound and system code the rest of the game is built on.
---

These are the parts every other part of the game leans on.

[Runtime](/tbs/engine/runtime) starts the game at power-up and handles the
interrupts, waits for each frame, reads the buttons, runs the fades and keeps
the sprite lists.

[Graphics](/tbs/engine/graphics) holds the screens that are mostly pictures,
like the title intro, the logos and the credits, plus the palette fades and the
decoders that unpack tiles and animation frames.

[Sound](/tbs/engine/sound) has the game's sound cues and the driver that plays
them, Nintendo's MusicPlayer2000 as this game links it.

[System](/tbs/engine/system) ties the cartridge together: its header and entry
point, how RAM is laid out, the code copied into fast RAM, the calls between
the banks of the main program, and the overlays that scenes are loaded from.

The retail game still contains three test rooms, built like any other scene.
They're under [Debug rooms](/tbs/engine/debug).
