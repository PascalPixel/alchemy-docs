About a third of The Lost Age's code is C so far, and nearly all of its data
is placed from source; the README's progress chart has the current figures.
These pages show that C, in `games/tla`. The rest still comes from the
cartridge through the scaffold in `recon/tla`, with drafts of the functions
being matched; neither is shown here.

Most of its C has not been read for meaning yet. A function or global named by
its address, such as `Func_02001140`, is a placeholder until evidence gives it
a name, and so is a field named by its offset.

Each folder's guide says what differs from The Broken Seal's, whose guides
describe the same engine. Every file is under [Source](/tla/source).
