[Start here](/docs/tbs/start), or with a guide: each folder of the code has one,
grouped by what it covers ([World](/docs/tbs/world), [Battle](/docs/tbs/battle),
[Menus](/docs/tbs/menus), [Game rules](/docs/tbs/game),
[Engine](/docs/tbs/engine)), and each links to its folder under
[Source](/docs/tbs/source).

Pages that find code by what you see in the game, the places and the
abilities, will come once a small build tool turns the scene and ability
tables into pages; until then the guides explain where to look.

In the cartridge the code sits in one bank per folder, in this order:
[runtime](/docs/tbs/source/src/runtime), [field](/docs/tbs/source/src/field),
[window](/docs/tbs/source/src/window), [game](/docs/tbs/source/src/game),
[menu](/docs/tbs/source/src/menu), [shop](/docs/tbs/source/src/shop),
[battle](/docs/tbs/source/src/battle), [effect](/docs/tbs/source/src/effect) and
[object](/docs/tbs/source/src/object), beside [graphics](/docs/tbs/source/src/graphics),
maps, [sound](/docs/tbs/source/src/sound), [system](/docs/tbs/source/src/system),
[debug](/docs/tbs/source/src/debug) and [scene](/docs/tbs/source/src/scene).
